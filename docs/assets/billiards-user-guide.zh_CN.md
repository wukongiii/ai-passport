# 逗宝台球记分器使用说明

## 先开始一局

左右短按切换大厅条目，中键进入“中八”。当前中八可以使用；追分、斯诺克为界面占位。
手动记分和本地语音播报无需联网，AI 语音控分需要联网并配置模型。

| 中八记分界面 | 左键 | 中键 | 右键 |
| --- | --- | --- | --- |
| 短按 | 左侧选手 +1 | 设置；播报中为停止播放 | 右侧选手 +1 |
| 长按 | 左侧选手 -1 | 返回大厅 | 右侧选手 -1 |
| 双击 | — | 开始语音录音 | — |

默认抢 10，可在玩法设置中调整，支持撤销。界面提示栏跟随物理按键位置；子页面按当前提示操作。
“应用设置 → 操作”可调整双击间隔；“声音”可开关语音播报、按 10% 一档调节音量。

## 用手机连接网络和设置

1. 在大厅进入“AI / 语音”，选择“热点配置”，中键进入；也可从“应用设置 → 网络”进入配网。
2. 手机连接设备屏幕显示的热点，无需密码。即使提示无法上网，也保留连接。
3. 打开自动弹出的配置页，或用浏览器访问 `http://192.168.4.1/`。
4. 展开“网络”，选择扫描到的 2.4 GHz Wi-Fi，填写密码，点击“连接并保存”。页面和设备均显示连接结果；成功后显示 Wi-Fi 名称和 IP，并保存网络供下次自动连接。最多保存 10 个网络，满后循环覆盖最早加入的网络。
5. 未找到网络时可重新扫描或手动填写名称。iPhone 热点请打开“最大兼容性”，扫描时保持在“个人热点”页面。

热点有倒计时，关闭后可从设备重新开启。若页面断开，先确认手机仍连着设备热点。
申请模型账号、查看控制台时需要手机能上网；建议先完成下文的账号准备，再连接设备热点填写配置。
“玩法配置 → 中八”可修改两位选手名字；AI 昵称和行为提示词位于独立的“AI 助手”分区，默认昵称为“逗宝”，与模型服务商名称无关。

## 通用 AI 模型要求

请找**具备中文语言理解能力、支持音频输入及工具调用的多模态大语言模型**。
它需要听懂“给左边加三分”等表达，结合选手名字、当前比分和玩法规则，返回能由记分器执行的操作。

当前固件要求同一模型接口同时满足：

| 能力 | 具体要求 |
| --- | --- |
| 接口 | 兼容 Chat Completions，使用完整 `/chat/completions` 请求地址及 API Key Bearer 鉴权 |
| 语音输入 | 接受消息中的 `input_audio`，内容为 Base64 编码的 WAV；设备发送 8 kHz、16 位、单声道录音 |
| 理解与执行 | 在带有音频的请求中支持 Tool / Function Calling，理解玩法上下文，返回函数名和 JSON 参数 |
| 响应 | 支持非流式响应，返回 `choices[0].message` 中的文字或单个 `tool_calls` |
| 请求参数 | 接受 `tools`、`tool_choice:auto`、`parallel_tool_calls:false`、`temperature:0`、`max_tokens:256`、`stream:false` |

仅支持文本对话、仅支持图片的“多模态”、单独的语音转文字（ASR）或语音合成（TTS）服务，都不足以直接完成当前语音控分。
仅提供 Responses API 或实时 WebSocket 的服务也不能直接填入当前配置；本版没有独立 ASR 接口或 ASR 到大模型的转接流程。
**模型不需要输出音频**：文字回复和实际比分由设备本地转为语音。

接口名称相同不保证所有能力兼容，具体型号、版本和接入点都需检测。
优先选响应快、回答简洁的模型。本版未提供服务商专用的关闭思考选项；依赖长推理的模型可能因回答限额而不兼容。

## 豆包 doubao-seed-2.0-mini 专门教程

这里使用火山方舟提供的**豆包 Seed 大模型 API**。需要申请 API 服务，不能把豆包聊天 App 的登录信息填入 API Key。
以下官网入口与模型信息核对于 2026-11-02，页面名称、可用版本和额度以控制台为准。

### 1. 注册和开通

1. 打开[火山引擎官网](https://www.volcengine.com/)，注册或登录账号，按网站提示完成身份验证及服务协议。
2. 进入[火山方舟控制台](https://ark.volcengine.com/)，选择自己使用的项目。
3. 在模型列表中找到 Doubao Seed 2.0 Mini，查看语音理解和 Function Calling 能力。按控制台提示使用试用额度或在[开通管理](https://ark.volcengine.com/region:cn-beijing/openManagement)开通相应模型；检查可用额度、余额及计费规则。
4. 打开该模型的 API 调用示例，选择 **Chat Completions** 方式，记录完整请求 URL 和示例中的 `model` 值。

官方[模型发布公告](https://docs.volcengine.com/docs/ark/model-release-announcement?lang=zh)列出了支持语音理解的 `doubao-seed-2-0-mini-260428`。这是版本示例，不能认为所有 Seed 系列、Mini 历史版本或精调接入点都支持相同能力。

### 2. 创建 API Key

打开[API Key 管理](https://ark.volcengine.com/region:cn-beijing/apiKey)，在相同项目下创建 Key 并复制。
如果设置了权限范围，需允许访问选定的 Model ID 或 Endpoint ID。
Key 只填入自己的设备配置页，不要放入作品介绍、截图或源码。额度与费用以服务商控制台为准，不承诺免费使用。

### 3. 填入记分器

重新连接设备热点，打开手机配置页，展开“模型连接”，选择一个空的模型配置位置：

| 配置项 | 填写方法 |
| --- | --- |
| 自定义名称 | 例如“豆包 Mini”，仅用于在设备上区分配置 |
| 模型 ID / Endpoint ID | 复制控制台示例的 `model` 原值，例如 `doubao-seed-2-0-mini-260428`；如果示例使用 `ep-...` 接入点，则填写那个完整值 |
| API URL | 北京区标准 Chat 接口为 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`；使用其他服务入口时复制与模型对应的完整地址 |
| API Key | 粘贴刚创建的 Key，不添加 `Bearer ` 前缀 |

`doubao-seed-2.0-mini` 是这里介绍的系列名称，**不要自行把它当作可调用的完整 Model ID**。
URL 要包含 `/chat/completions`，不能只填 Base URL、控制台网页、`/responses` 或语音识别服务地址，也不要重复追加路径。
地址、模型标识和 Key 必须匹配同一服务与权限。

### 4. 保存并检测

点击“保存、启用并检测”，查看**文本、工具、音频**三项结果，均通过后再试记分。
也可在设备模型详情中点击“检测”。检测最多发送三次少量 API 请求，可能产生费用；使用固定测试语音，不上传麦克风录音，也不修改比分。失败后修正配置，再点“检测已保存模型”。

最多保存 4 份模型配置，通过“设为当前”切换。自定义名称、助手昵称、模型 ID 是三个不同的设置。
检测通过只表示样例通过，不能代替实际语音测试。

### 5. 试一句语音指令

进入中八，双击中键开始录音，说“左边加三分”，短按中键发送；长按中键可取消。录音最长 10 秒，到时自动发送，建议简短清晰。
成功后左侧选手增加 3 分，界面显示实际比分；开启播报且音量非零时会读出比分。
还可试“把右边设为四分”“撤销刚才的操作”“现在几比几”，或直接使用已配置的选手名字。
分数受当前抢局目标和玩法规则限制。实际记分操作会改变当前比赛，测试后可以撤销。
播报中短按中键停止播放。

## 配置遇到问题

| 现象 | 优先检查 |
| --- | --- |
| 尚未联网，检测立即失败 | 设备网络状态、Wi-Fi 名及 IP；手机连上设备热点不等于设备已经能访问互联网 |
| HTTP 401 | Key 是否完整、有效，是否误加 `Bearer ` 前缀 |
| HTTP 403 | 项目、Key 权限、模型是否开通，以及服务商返回的具体原因 |
| HTTP 404 | 完整 API URL、控制台示例的 Model ID / Endpoint ID，是否使用了停用版本 |
| HTTP 429 | 服务商额度、限流及余额；按返回信息处理后重试 |
| 文本通过，工具或音频失败 | 该版本与接入点是否支持相应能力，尤其是否能同时处理音频和工具调用 |
| 有回复但无声音 | “声音 → 语音播报”是否开启、音量是否非零，可先运行本地播放测试 |
