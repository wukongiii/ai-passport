# 逗宝台球记分器

把随身设备变成台球记分器。三键直接加减比分，也能用语音说出记分指令，让“逗宝”理解并操作。支持中八双人记分、撤销、选手改名和比分播报，手机打开配置页即可设置网络和 AI 模型。手动记分无需联网，语音控分需连接 Wi-Fi 并配置兼容模型。

[观看实机演示视频（约 80 秒）](https://github.com/wukongiii/ai-passport/blob/feature/billiards-scorekeeper/assets/videos/doubao-billiards-demo.mp4)

目前中八玩法可用，追分、斯诺克为界面预览，尚未开放记分。封面为 AI 生成的宣传插画，演示视频为实机拍摄。

[查看使用说明与 AI 模型配置教程](https://github.com/wukongiii/ai-passport/blob/feature/billiards-scorekeeper/docs/assets/billiards-user-guide.zh_CN.md)。
